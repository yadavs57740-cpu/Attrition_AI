# Dataset Instructions

The problem statement says to build using the supplied dataset. The organizer's dataset was not attached in this chat, so this project includes an offline synthetic/demo dataset.

For the actual hackathon:
1. Take the dataset supplied by your organizers.
2. Save it as `data/employee_attrition.csv`.
3. Ensure the target column is `Attrition` with values such as `Yes` / `No`.
4. Start the app.
5. Use the Model Lab numbers generated from the official dataset in the final presentation.

Do not present the bundled synthetic dataset's metrics as results on the organizer dataset.
